# Scientific Problem Statement Skill

A reusable cross-disciplinary LLM skill for evidence-grounded MSc/PhD and research-paper problem statements, extracted from the user's evolving *Research Problem Statements: Critical Reading and Methodological Quality* notes (through v.0.0.6).

## Entry point
Read [SKILL.md](SKILL.md). It determines when to load each supporting reference. The skill teaches reasoning and writing behaviour, **not a graded methodological quality assessment instrument**.

## Structure
```text
scientific-problem-statement/
├── SKILL.md

├── references/

```

## Example triggers
- "Read the literature and find a genuine research problem."
- "Rewrite my Statement of the Problem without changing its scientific scope."
- "Analyse whether this research gap is defensible."
- "Compare the problem statements from PhD theses and teach me their argumentation."

## Operating principles
Read sources before claiming gaps; synthesise rather than list; check competing evidence; keep inference bounded; never fabricate citations; preserve authorised research content and paragraph constraints.

## Status
Initial skill version 0.1.0. Reference notes are interpretive and some case studies have only abstract-level verification; do not present them as full-text confirmed. Upgrade references only after directly checking the source.
